# NorteDigitalDev — sitio principal

Sitio de **NorteDigitalDev**: funciona como link de la bio de Instagram (accesos rápidos arriba) y como portfolio completo (proyectos, servicios con precios, cómo trabajo, preguntas y contacto).

## Tecnologías

HTML, CSS y JavaScript puro, sin dependencias. Tipografía Archivo (Google Fonts).

## Editar

- WhatsApp: al principio de `js/app.js`.
- Cada botón con `data-wa="..."` abre WhatsApp con ese mensaje ya escrito.
- Capturas de proyectos: `img/proyectos/` (formato webp, 960 × 720).
